# mend

[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/hidden-spec-cli-01-run-20261122)
[![repo](https://img.shields.io/badge/repo-arianda17%2Fmend--lane2-informational)](https://github.com/arianda17/mend-lane2)

mend applies an edit that an AI model wrote to a tree of text files, in four formats: unified diff, SEARCH/REPLACE blocks, V4A patch, and JSON tool calls.

See SPEC.md for the full specification. Run with `node main.ts [options] [PATCH]`.
